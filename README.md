# Curbside Junk Removal

San Diego curbside junk pickup — a service of [Fred's Junk Removal](https://www.fredsjunkremoval.com). Stage it at the driveway. You don't need to be home. Posted prices from **$69**.

- **GitHub:** [fasiegel/curbside-junk-removal](https://github.com/fasiegel/curbside-junk-removal)
- **Production domain:** [curbsidejunkremoval.com](https://curbsidejunkremoval.com) (attach in Vercel after import)

## Deploy on Vercel

Import this repo (one click):

[https://vercel.com/new/clone?repository-url=https://github.com/fasiegel/curbside-junk-removal](https://vercel.com/new/clone?repository-url=https://github.com/fasiegel/curbside-junk-removal)

Framework is auto-detected (Vite). Build command: `npm run build`.

Then in the project: **Settings → Domains → Add** `curbsidejunkremoval.com` and `www.curbsidejunkremoval.com`.

## Stack

- TanStack Start + React 19
- Tailwind CSS v4
- Vite / Nitro (Vercel)

## Scripts

```bash
npm install
```
